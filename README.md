# 杰森笔记

一款面向个人使用的读后感、观后感笔记工具。支持新建、编辑、删除、搜索、分类、评分、标签及思维导图。

## 使用说明

- 内容会自动保存在当前浏览器中，刷新后仍然保留。
- 清理浏览器网站数据后，笔记会被清除。
- 思维导图中可直接修改节点，点击“＋”添加子主题，点击“×”删除分支。
- 手机端可点击右下角“＋速记”，直接创建空白笔记并开始输入正文。

## 安装到 iPhone 主屏幕

1. 使用 Safari 打开 [杰森笔记](https://shiguang-notes-jg.z1348566337.chatgpt.site)。
2. 点击 Safari 底部的“分享”按钮。
3. 选择“添加到主屏幕”，并开启“作为网页 App 打开”。
4. 点击“添加”，以后可以直接从桌面图标启动。

安装不会自动同步不同设备中的笔记。当前内容仍只保存在创建笔记时使用的浏览器中，请勿随意清理网站数据。
